# Agent work journal

This is the chronological continuity log for `elspice-mna`: more concrete than
commit messages and less formal than architecture decisions. Read the newest
month's top entry before continuing prior work.

Entries live in `YYYY-MM.md`, newest first. Each entry records what was asked,
what was found, what changed, verification, and what remains. Include an entry
in every commit. Obtain its timestamp with `date '+%Y-%m-%d %H:%M'`; do not
trust an ambient date.

Do not rewrite history. If work is reverted or corrected, add a new entry that
links to the earlier one. Use a decision document for lasting rationale and a
gotcha document for a reproducible trap.
